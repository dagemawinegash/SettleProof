A TRACEABLE WORKFLOW

From files to a paper trail.

Four steps. Evidence behind every result.

  1. 01
    Bring both sides

    Upload a payment export and bank deposits in the supported USD CSV format.

  2. 02
    A program written for your files

    The agent writes Python and runs it in a separate CreateOS sandbox.

  3. 03
    Check every claim

    An independent checker recalculates amounts, checks source rows and coverage, and rejects unsupported matches. Rejected code can be revised up to three times.

  4. 04
    Keep the evidence

    Inspect the report, original records, code and execution attempts. A second execution must reproduce the result.

A difference is a reason to investigate. Settlement timing or incomplete exports can explain missing deposits; a difference alone does not prove lost money.
